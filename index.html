AIの翻訳が止まったときの直し方

1つずつ、順番にやれば大丈夫です。

まず、シートから手をはなします

直している間に別のところをさわると、こわれたところがふえてしまいます。

❌ 行や列を消さない
❌ シートの「保護」を消さない(シートを守っている設定です)
❌ シートをコピーして作り直さない
❌ 最初の準備を、もう一度ぜんぶやらない
❌ 別のAIにも同時にたのまない
(同じ行を取り合って、ぐちゃぐちゃになることがあります)
❌ 作業中のパソコンを閉じない
「もう一度やって」とAIに言うだけでは、このエラーは直らないことが多いです。

どのエラーが出ましたか？

画面に出ている文字と、見くらべてください。英語や数字の意味は、わからなくて大丈夫です。

🚪 シートが見つからないとき

いちばん多い原因と考えられるもの
🚪シート
(部屋)
🔑Googleのメールアドレス
(カギ)

AIが使っているGoogleのメールアドレスでは、シートの部屋が開かないことがあります。部屋の持ち主が「このカギも入っていいよ」と追加すれば開きます。

シートの住所をくらべる

シートの住所は、画面の上の細長い欄に出ている https で始まる文字です。

いつもAIにはっている文に書いてある住所と、いま開いているシートの住所を見くらべます。

/d/ と /edit のあいだの長い文字だけ見ます。

正しい住所に直して、新しい会話でたのみ直します。(「新しいチャット」をおします)動いたらおしまいです。

AIのカギを調べる

ChatGPTの左下の丸いマークをおして、「設定」を開きます。

「アプリ」か「コネクタ」という名前のところを開きます。Google と書いてあるものをおします。

そこに出ているメールアドレスを、紙に書きます。

メニューの名前は変わることがあります。見つからないときは、ここで止まって「こまったとき」へ。

シートにカギを追加する

「共有」でメールアドレスを入れることが、カギの追加です。

  1. シートを作ったときのGoogleのメールアドレスでログインして、シートを開きます。
  2. 右上の「共有」をおします。
  3. さっき紙に書いたメールアドレスを入れます。
  4. 「編集者」をえらびます。
  5. 「送信」をおします。
紙に書いたメールアドレスだけ入れます。ほかの人のものは入れません。

新しい会話でたのむ

前の会話は使いません。

新しい会話を開きます。(「新しいチャット」をおします)

いつもAIにはっている文を、同じようにはります。

つなぎ直す

ChatGPTの「設定」で、さっき見た Google のところを開きます。一度切って、もう一度つなぎます。

出てくる画面で「許可」のボタンをおします。

「新しいチャット」をおして、いつもAIにはっている文を、同じようにはります。

🚧 403 などが出るとき

🚧門番
(もんばん)
→
🌐ホームページ

AIの作業部屋には門番がいます。行ってよいホームページの一覧(名簿)にないところには、行かせてもらえません。AIのミスではありません。名簿に書き足します。

「管理者に聞いて」と出ても、自分ひとりで使っている人は、自分で次の設定を見ます。

設定を開く

  1. Claudeアプリの左下の自分の名前をおします。
  2. 「設定」→「Capabilities」を開きます。(日本語の画面では「機能」のような名前)
  3. 「Code execution and file creation」をオンにします。(新しい画面では「Create and edit files」)
  4. 「Allow network egress」をオンにします。これが門番のスイッチです。

英語の意味は、わからなくて大丈夫です。同じ文字をさがしておすだけです。

名簿にホームページを書き足す

次の3つを、まとめてコピーできます。

script.google.com
script.googleusercontent.com
naokijodan.github.io

「Allow network egress」の近くに書きこむ欄があれば、この3つを1行ずつ入れます。

画面の上に ▼ があって「Edit cloud environment」が出る人だけ

画面の上にある、会話のタイトルの右の ▼ をおして、「Edit cloud environment」をえらびます。

出てきた画面で「Custom」をえらびます。

「Allowed domains」に3つを1行ずつ入れます。もとからある名簿も使うか聞かれたら、使うほうをえらびます。

ここで止まります。欄がなくても、あなたのミスではありません。ほかのやり方をさがさず「こまったとき」へ。

新しい会話でたのむ

「新規作成」をおして、新しい会話を開きます。いつもAIにはっている文を、同じようにはります。

🎉

動きました

AIが「続けてよいですか？」と聞いてきたときだけ答えて、あとは待ちます。

待っている間は、シートの行や列を消さないでください。

🙋 こまったとき
